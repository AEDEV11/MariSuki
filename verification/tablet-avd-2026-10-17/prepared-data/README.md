# MariSuki tablet scenario data

These files are prepared for the staging tablet demo. The CSV contains seven products and the Excel workbook contains six different products, so importing both produces 13 items without duplicate barcodes. All products include a category, stock unit and retail price, stock and purchase cost, plus a wholesale selling unit and price. Five categories are represented: Snacks (4), Beverages (3), Pantry (3), Noodles (1), and Canned Goods (2).

The `product-images/` folder has one square photo per catalog row, numbered in the same order as the combined CSV and Excel product lists. Product names and barcode values are intended for a demo catalog; review package sizes and local pricing before using this dataset in a real store.
